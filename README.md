# Tidewater Swim Academy

A four-page swimming-academy website built with plain HTML, CSS and vanilla JavaScript.

## GitHub Repository

Repository: https://github.com/jgn00/Tidewater-Website

## Pages

- `index.html` — Home
- `services.html` — Programs and fees
- `about.html` — Academy story and coaching team
- `contact.html` — Contact details and trial booking form

## Run it

Open `index.html` in a browser, or use a simple local server (recommended so the map and linked files behave consistently):

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Project files

- `styles.css` — all visual styling and responsive rules
- `main.js` — navigation, animations, filters, FAQ and frontend form validation
- `images/` — local swim photography
- `favicon.svg` — Tidewater wave mark shown in the browser tab
- `MIGRATION.md` — migration details and known online-only extras
- `SITE-SPEC-AND-SITEMAP.md` — required planning material


## Notes

- The booking form gives a realistic frontend confirmation but does not send data to a server.
- Google Fonts and the embedded OpenStreetMap map require an internet connection. The pages, CSS, JavaScript and swim photographs are all local.
